Secure CI/CD with Flask and GitLab

A small Flask service deployed by a self-hosted GitLab CI/CD pipeline onto a hardened Ubuntu server.

What this deployment demonstrates

  • Self-hosted GitLab CE with a shell-executor runner
  • Lint, test and deploy pipeline with a post-deploy health check and rollback
  • Least-privilege deployment through a single sudo-allowed script
  • Server hardening: UFW, Fail2ban, key-only SSH, automatic security updates
  • Application served by gunicorn under systemd behind nginx
